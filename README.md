## 📌 Sobre o Projeto

O **Obra Certa** é um Micro-SaaS B2B focado em resolver a dor de pedreiros, marceneiros, eletricistas e outros prestadores de serviços da construção civil: **a demora e o amadorismo na entrega de orçamentos**.

Com o Obra Certa, o profissional cria uma proposta detalhada no celular em menos de 2 minutos e envia um link direto para o cliente via WhatsApp. O cliente visualiza a proposta formatada e **assina digitalmente direto na tela do celular**, confirmando o serviço sem complicações.

---

## 🚀 Funcionalidades do MVP

- 📝 **Criação Rápida de Orçamentos:** Adição simplificada de materiais, mão de obra, prazos e valores totais.
- 📱 **Link Interativo para WhatsApp:** Envio da proposta via link público sem necessidade de baixar PDFs pesados.
- ✍️ **Assinatura Digital no Celular:** Coleta de assinatura via touch screen direto na página do orçamento.
- 🔔 **Acompanhamento de Status:** Notificação em tempo real quando o orçamento for *Rascunho*, *Visualizado* ou *Aprovado*.
- 📲 **PWA (Progressive Web App):** Funciona como aplicativo instalável na tela inicial do celular do profissional.

## 🛠️ Tecnologias Utilizadas

- **Frontend & Server Components:** [Next.js](https://nextjs.org/) (App Router & TypeScript)
- **Estilização & Interface:** [Bootstrap 5](https://getbootstrap.com/) & [Bootstrap Icons](https://icons.getbootstrap.com/)
- **Backend & Banco de Dados:** [Supabase](https://supabase.com/) (PostgreSQL + RLS Security + Auth)
- **Assinatura Canvas:** `canvas-confetti` / Canvas API HTML5
- **Deploy Sugerido:** [Vercel](https://vercel.com/)
